# private/ — rights-restricted reference material (content manifest)

This directory holds only legally-untrackable content: in-copyright scans,
page captures, paywalled extracts, and working registers that must not
enter the tracked tree. Nothing here is committed to git; its inventory of
record lives in the sibling tracked `AGENTS.md`-governed documentation when
the roadmap lands it. Acquisition of restricted material records its route
and enough detail to re-obtain it, per the placement rules.
